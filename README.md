# starcitizen.today

A complete rebuild of [starcitizen.today](https://starcitizen.today) — a Star Citizen community site (ship reviews, trivia, in-game event updates).

## Branches

- **`main`** — the new site. Only new work lives here; this is what everyone sees.
- **`V2starter`** — same clean base plus a `reference/` folder containing the legacy Jekyll site, kept for reference during the rebuild. That folder may be merged later or simply removed.

## References

- Legacy site source: [`reference/`](./reference/) on the `V2starter` branch
- Original repo: <https://github.com/starcitizen42/starcitizen42.github.io> (git remote `upstream`)
